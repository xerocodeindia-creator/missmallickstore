# Miss Mallick Store Website

A responsive, static business-information website for Miss Mallick Store.

## Pages
- `index.html` — homepage and service overview
- `about.html` — business information
- `contact.html` — contact details
- `privacy-policy.html` — privacy policy
- `terms.html` — terms of service

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the default branch and the `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

This repository contains static HTML and CSS and does not require a build command.

The site content is based on the Udyam certificate details supplied for this project.
